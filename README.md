# Poe's Times Tables

A simple, free multiplication and division flashcard web app for Presley. Tables 1–10, no accounts, no ads, no tracking. Works on a phone and can be added to the home screen for offline practice.

Pick tables, Times / Divide / Mix, and a mode: full-screen flip cards (10-card memory drill), type-the-answer practice, or the Demon Hunter Quest (a 10-question multiple-choice boss battle with 3-second critical hits, hearts, and healing potions). Quest art in `art/` is original. Last settings, a sticker collection, and a one-time secret code stay on the device. Cheers use fan-style song-title puns — they are not quotes from the artists.
