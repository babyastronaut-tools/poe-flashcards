# Poe's Times Tables

A simple, free multiplication flashcard web app for Presley. Tables 1–10, no accounts, no ads, no tracking. Works on a phone and can be added to the home screen for offline practice.

Pick tables and a mode, then practice. Last settings, a sticker collection, and a one-time secret code stay on the device. Cheers use fan-style song-title puns — they are not quotes from the artists.
